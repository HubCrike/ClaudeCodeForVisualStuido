## 🎮 Quick Start

1️⃣ Open Visual Studio

2️⃣ Choose **"Open Claude Chat"** from the Extensions menu

3️⃣ Type your prompt and start chatting with Claude!

## ⚙️ Configuration

- Config file path: `~/.claude/settings.json`
  - Windows example: `C:\Users\<username>\.claude\settings.json`
- Supported in config file or environment variables:
  - `ANTHROPIC_API_KEY`
  - `ANTHROPIC_AUTH_TOKEN`
  - `ANTHROPIC_BASE_URL`
- The extension uses an embedded Agent SDK Service (Node.js); ensure Node.js is installed and `node` is available in your system PATH

## 📋 Logs

Logs are written to:

```
%LOCALAPPDATA%\ClaudeCodeForVS\Logs
```

Check the logs if you encounter any issues - they'll help you quickly identify problems.
